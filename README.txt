SNAPLOCK — LANDING PAGE (VERSÃO 2)

Arquivos:
- index.html: estrutura e conteúdo da página
- style.css: identidade visual, layout e responsividade
- script.js: menu mobile
- assets/snaplock-avatar.jpg: mascote enviado para o projeto

Como visualizar:
1. Extraia o arquivo ZIP.
2. Mantenha index.html, style.css, script.js e a pasta assets juntos.
3. Abra index.html no navegador.

Observações:
- A página é uma landing page estática. Cadastro, login e funções do aplicativo ainda não estão conectados a um backend.
- As imagens de exemplo de fotografias e as fontes são carregadas pela internet.
- O texto foi alinhado às funcionalidades descritas no material do projeto SnapLock. A página não afirma que os recursos de segurança já estejam implementados.
